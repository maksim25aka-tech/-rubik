🧊 Описание
Симулятор кубика Рубика (4×4) — это консольная программа, моделирующая головоломку «Кубик Рубика 4×4» (Rubik's Revenge). Программа позволяет:

Визуализировать состояние куба в виде развёртки

Выполнять повороты внешних граней: U, D, L, R, F, B

Выполнять повороты внутренних слоёв: u, d, l, r, f, b (малые буквы)

Перемешивать куб случайной последовательностью ходов

Отображать состояние после каждого хода

Проект содержит 8 полноценных реализаций на разных языках программирования. Все версии используют консольный вывод и поддерживают интерактивный режим ввода команд.

✨ Возможности
Функция	Описание

Повороты внутренних слоёв	u, d, l, r, f, b

📦 Установка и запуск
Каждая реализация находится в отдельной папке. Для запуска требуется соответствующий компилятор/интерпретатор.

Язык	Файл	Команда запуска
Python	rubik.py	python3 rubik.py
Go	rubik.go	go run rubik.go
Rust	rubik.rs	cargo run
C++	rubik.cpp	g++ -std=c++17 -o rubik rubik.cpp && ./rubik
Java	Rubik.java	javac Rubik.java && java Rubik
C#	rubik.cs	dotnet run
Ruby	rubik.rb	ruby rubik.rb
Node.js	rubik.js	node rubik.js
🎮 Использование
После запуска появляется интерактивная консоль:

text
Доступные команды:
  U, D, L, R, F, B   - поворот внешней грани
  u, d, l, r, f, b   - поворот внутреннего слоя
  scramble            - перемешать куб (50 ходов)
  reset               - собрать куб
  quit                - выход
  help                - показать справку
Пример ввода:

text
> U
> R
> u
> scramble
> reset
> quit
